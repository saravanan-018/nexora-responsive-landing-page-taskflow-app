# Bloom Task Manager

A colourful, responsive personal task manager built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Run it

Open `index.html` in a modern browser. Tasks, custom lists, and the colour theme are saved in that browser's local storage.

## Features

- Reusable task rows, stat cards, filters, navigation, and modal form.
- Add and edit tasks with required title validation, notes, lists, due dates, times, and priority.
- Mark tasks complete, filter by status, search, and sort.
- Today, upcoming, and completed views, plus custom lists.
- Responsive layout, subtle motion, toast feedback, and a dark theme.
